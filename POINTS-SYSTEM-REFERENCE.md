# Points, XP, and Coins - Quick Reference Guide

## 📊 Points System Overview

### Quiz Points Calculation

```
Base Points = (Correct × 5) - (Wrong × 1) - (Coins Used × 10)

Bonuses:
+ Perfect Score (100%): +50 points
+ Speed Bonus (<30 sec): +1 per question
+ 2x Power-Up Active: All points × 2

Final Points = Base Points + Bonuses
```

### Study Session Points

```
Base Points = Minutes Studied × 5

Bonuses:
+ Perfect Session (≥80% quiz): +25 points
+ Long Session (>60 min): +10 per extra 30 min
+ 2x Power-Up Active: All points × 2

Penalties:
- Early Finish: -25 points

Final Points = Base Points + Bonuses - Penalties
```

## 💰 Coins System

### Coin Rules
- **Maximum per Quiz:** 3 coins
- **Cost per Use:** -10 points
- **Bonus Coin:** Awarded for perfect score (100%)
- **Purpose:** Reveal correct answers during quiz

### Coin Strategy
```
Using 1 coin: -10 points (may help get +5 for correct answer)
Using 2 coins: -20 points
Using 3 coins: -30 points

Perfect score without coins: +50 bonus + bonus coin
Perfect score with coins: No bonus (not 100% on your own)
```

## ⚡ XP (Experience Points)

### XP Calculation
```
XP = Points × 1.5
```

### Examples
- 100 points = 150 XP
- 500 points = 750 XP
- 1,000 points = 1,500 XP

**Note:** XP is for display purposes. Points are used for actual progression.

## 🎓 Tips for Maximizing Points

### High-Value Activities
1. **Study Consistently:** Build streaks for bonus points
2. **Aim for Perfect Scores:** +50 bonus + bonus coin
3. **Use Power-Ups Wisely:** 2x points during long sessions
4. **Complete Quests:** Easy points for regular activities
5. **Study Longer:** Bonus points after 60 minutes

### Avoid Point Loss
1. **Don't Use Coins:** -10 points each, prevents perfect score bonus
2. **Don't Quit Early:** -25 point penalty
3. **Study Regularly:** Losing streaks means missing bonus points
4. **Answer Carefully:** -1 point per wrong answer

### Optimal Strategy
```
1. Start study session (25-30 minutes)
2. Review material thoroughly
3. Take quiz without using coins
4. Aim for 100% accuracy
5. Earn: ~150-200 points per session
6. Build 7-day streak: +50 bonus
7. Complete quests: +25-75 bonus

Weekly potential: 1,000-1,500 points
```
